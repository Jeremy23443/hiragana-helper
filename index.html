華人背平假名的方法

整理自網路上中文學習者的經驗、日文教學網站和字源資料。重點是：別只靠死背五十音順序，用你已經會的漢字當掛勾。

字源法：從認得的漢字出發

平假名是漢字草書再簡化的結果，46 個字都有對應的漢字。華人學這個最划算，因為漢字本來就認得。

安→あ　加→か　不→ふ　仁→に

不少字源的讀音也接近假名：太 ta、奈 na、末 ma、毛 mo、也 ya、由 yu、利 ri、留 ru、呂 ro、和 wa。日本學者也承認有些字的演變過程說不清，所以字源當「掛勾」就好，不必背演變細節。

圖像加諧音聯想

把字形想成一個畫面，再配中文諧音，越誇張越好記。

ろ 像 3 →「媽媽要數到 3 囉 (ro)」
ち 肚子往右挺 →「吃 (chi) 飽了」

自己編的聯想比別人給的更牢，看到不順眼的口訣就換掉。

易混字並排比

照五十音順序背，像的字會分散在不同行，永遠搞混。把長得像的放在一起，找出一個關鍵差異就好。「易混淆」頁就是照這個方法整理的。

手、口、眼、耳一起用

看字形、唸出聲、手寫一次、聽發音。平假名保留了毛筆的筆勢，照筆順寫，字形才不會歪，也比較容易分出 さ／ち、ぬ／め 這種字。

字卡打散抽考，答錯的再考

一面假名、一面讀音，洗亂了抽。答錯的字隔一陣子再考一次。這個小助手會自動記錄：答錯的字變紅點，連對 3 次變綠點。

先平假名，再片假名

兩套同時學容易混（片假名有自己的易混字，例如 シ／ツ、ソ／ン）。平假名穩了再開始片假名，會輕鬆很多。

每天 15 分鐘的練習流程

  1. 五十音表點開今天要學的那一行，看字源和口訣，跟著發音唸。

  2. 到「易混淆」看跟這一行有關的組別。

  3. 練習：「看假名選讀音」20 題，再做「看讀音找假名」10 題。

  4. 用「拼音輸入」打羅馬字。考試要寫，光會選不夠。

  5. 單字頁打開「遮住意思」，唸出單字並說出英文意思。

  6. 隔天第一件事：先練待加強的字。

華人特別要注意的發音

  • 清音和濁音（か／が、た／だ）：國語的ㄍ、ㄉ、ㄅ喉嚨不震動；日語濁音要震動。摸著喉嚨練，有震動的才是濁音。
  • う 不要嘟嘴發成「烏」，嘴唇放鬆。
  • ら行 舌尖輕彈一下，介於 l 和 r 之間。
  • ふ 不是英文的 f，是輕輕吹氣。
  • 拍數會改變意思：おばさん（阿姨）／おばあさん（奶奶）、きて／きって、きや／きゃ。

怎麼拿到 Google API 密鑰（約 10 分鐘，有免費額度）
  1. 到 Google Cloud Console 建立一個專案，綁定帳單帳戶。每月有免費額度，個人練習用不完。
  2. 在「API 和服務 → 程式庫」搜尋 Cloud Text-to-Speech API，按「啟用」。
  3. 到「API 和服務 → 憑證」，按「建立憑證 → API 金鑰」。
  4. 編輯這把金鑰：應用程式限制選「網站」，加入 https://你的帳號.github.io/*；API 限制只勾 Cloud Text-to-Speech API，然後儲存。
  5. 用 iPhone 的 Safari 打開你的 GitHub 網址，在這裡貼上金鑰，按「儲存密鑰」，再按「測試發音」。

密鑰只存在這台裝置的瀏覽器裡，只會傳給 Google 產生語音，不會寫進網頁原始碼。加了網站限制，別人拿到也不能在其他網站使用。

加到主畫面：在 Safari 按下方「分享 → 加入主畫面」。從主畫面打開時要再貼一次密鑰，因為 iPhone 會把主畫面 App 和 Safari 的資料分開存。
